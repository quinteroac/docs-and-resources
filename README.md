# Docs and Resources

A personal collection of documentation, articles, book summaries, tutorials, guides, and useful resources.

This repository serves as a centralized place to collect, organize, and share knowledge across different topics.

## Contents

| Category | Description |
|---|---|
| [Articles](./articles/) | Interesting articles, research, and technical insights. |
| [Books](./books/) | Book summaries, reading notes, and key takeaways. |
| [Tutorials](./tutorials/) | Step-by-step tutorials and practical examples. |
| [Guides](./guides/) | Reference guides, explanations, and best practices. |
| [Resources](./resources/) | Useful links, tools, references, and learning materials. |

## Organization

```text
docs-and-resources/
├── README.md
├── articles/
├── books/
├── tutorials/
├── guides/
└── resources/
```

Each directory contains Markdown documents organized by topic. Content may include original notes, summaries, external references, and practical examples.

## Purpose

- Keep useful information organized and accessible.
- Document concepts, discoveries, and lessons learned.
- Summarize books, articles, and technical documentation.
- Collect tutorials, tools, and references for future use.
- Build a growing personal knowledge base.

## Notes

Content is collected for personal learning, research, and reference. External sources are credited and linked whenever applicable.

This repository is continuously updated as new topics and resources are explored.
